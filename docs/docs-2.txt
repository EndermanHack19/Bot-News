## 📨 Для начала рассылки вам потребуется:

1. **Токен вашего бота** [**Discord**](https://discord.com/developers/applications)**.**
2. **Добавьте вещего бота на сервер.**
3. **Текст сообщения:** обычный или в формате Embed.
4. **Использовать команду** `/token` для установки токена.
5. **Выбираем «Установить токен».**

---

## 📝 Как работает рассылка

Чтобы начать рассылку, кликните правой кнопкой мыши (ПКМ) по сообщению и выберите в меню **«Приложение» → «Рассылка (Бета)»**.
===END===

## 🌸 Как создать верификацию

### Шаг 1: Добавьте роль для верификации

Используйте команду `/ver roles`, чтобы установить роль, которую участник получит после успешной верификации. (Роль удаляется после прохода верификации)

### Шаг 2: Добавьте изображение для Embed

Используйте команду `/ver image`, чтобы установить изображение, которое будет отображаться в Embed-сообщении для верификации.

### Шаг 3: Запустите процесс верификации

Введите команду `/ver start`, чтобы начать процесс верификации для участников.

Текст верификации не может быть изменён из-за технических неполадок или нежелания участников вносить правки.

## 🏠 Переменные сервера

| Переменная | Описание | Пример значения |
|---|---|---|
| `{server_name}` | Название сервера | `My Awesome Server` |
| `{server_avatar}` | URL иконки сервера | `https://cdn.discordapp.com/icons/...` |
| `{server_members}` | Всего участников на сервере | `1500` |
| `{server_humans}` | Количество людей (без ботов) | `1450` |
| `{server_bots}` | Количество ботов | `50` |
| `{server_id}` | ID сервера | `123456789012345678` |
| `{server_created}` | Дата создания сервера | `15.03.2020` |
| `{server_created_timestamp}` | Относительное время создания | *3 года назад* |
| `{server_boost_level}` | Уровень буста (0-3) | `2` |
| `{server_boosts}` | Количество бустов | `14` |
| `{server_vanity}` | Кастомная ссылка-приглашение | `myserver` |
| `{server_owner}` | Упоминание владельца сервера | `@Owner` |
| `{server_owner_name}` | Имя владельца без упоминания | `Owner` |
| `{channel_count}` | Общее количество каналов | `45` |
| `{online_count}` | Участников онлайн | `320` |

---

## 👤 Переменные пользователя

| Переменная | Описание | Пример значения |
|---|---|---|
| `{user_mention}` | Упоминание пользователя | `@Username` |
| `{user_nick}` | Имя пользователя | `Username` |
| `{user_display_name}` | Отображаемое имя (никнейм на сервере) | `Cool Nickname` |
| `{user_avatar}` | URL аватара пользователя | `https://cdn.discordapp.com/avatars/...` |
| `{user_id}` | ID пользователя | `987654321012345678` |
| `{user_created}` | Дата регистрации аккаунта Discord | `01.01.2019` |
| `{user_created_timestamp}` | Относительное время регистрации | *4 года назад* |
| `{user_joined}` | Дата входа на сервер | `25.12.2023` |
| `{user_joined_timestamp}` | Относительное время входа на сервер | *только что* |
| `{user_color}` | Цвет роли пользователя (HEX) | `#FF5733` |
| `{user_is_bot}` | Является ли пользователь ботом | `Да` / `Нет` |
| `{member_number}` | Порядковый номер участника на сервере | `1501` |

---

## 🔗 Переменные пригласившего

| Переменная | Описание | Пример значения |
|---|---|---|
| `{inviter_mention}` | Упоминание пригласившего | `@Inviter` |
| `{inviter_name}` | Имя пригласившего | `Inviter` |
| `{inviter_id}` | ID пригласившего | `111222333444555666` |
| `{inviter_avatar}` | URL аватара пригласившего | `https://cdn.discordapp.com/avatars/...` |

**Важно:** Переменные пригласившего работают только если у бота есть право **«Управление сервером»**.

---

## 📅 Дата и время

| Переменная | Описание | Пример значения |
|---|---|---|
| `{date}` | Текущая дата | `25.12.2024` |
| `{time}` | Текущее время | `14:30` |
| `{nl}` или `\n` | Перенос строки | *(новая строка)* |

### Простой Embed

```
{
  "embeds": [\
    {\
g      "title": "👋 Добро пожаловать!",\
      "description": "Привет, {user_mention}!\n\nТы **{member_number}**-й участник **{server_name}**",\
      "color": 5763719,\
      "thumbnail": {\
        "url": "{user_avatar}"\
      }\
    }\
  ]
}
```
